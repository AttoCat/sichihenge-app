2025年6月に開催したクイズ大会「[七変化杯](https://sichihenge.general-cat.com)」の得点管理システムです。

エントリー時に登録したメールアドレス・パスワードと、参加者自身のLINEアカウントを連携させることで、エントリー情報や成績を確認できるようにしました。

基本的にLINEトーク画面を唯一のクライアントとしているため、Webは連携のためにLINE上で開くことを想定しています。

このフロントにはHTMXを採用し、JS(TS)なしでトークン払い出し→連携 のフローを実現しました。
バックエンドにはHonoを採用し、ランタイムにDenoを使用したので Deno Deploy上にデプロイしました。データベースにはSupabaseを使用しています。
